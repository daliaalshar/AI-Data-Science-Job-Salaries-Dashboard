
# AI & Data Science Job Salaries Dashboard 2026

## Project Overview
This project presents an interactive Excel dashboard designed to analyze salaries in Artificial Intelligence (AI) and Data Science careers.

The dashboard helps explore salary trends, compare job roles, and understand how experience levels influence salaries.

## Project Objectives
- Analyze salary trends across AI and Data Science job roles.
- Compare average salaries by job title.
- Examine salary differences across experience levels.
- Identify high-paying positions.
- Provide interactive visualizations to support data-driven insights.

## Tools & Technologies
- Microsoft Excel
- Data Cleaning & Preprocessing
- Pivot Tables
- Data Visualization
- Interactive Dashboard
- Excel Formulas

## Dashboard Features
- **Average Salary:** Displays the average salary in USD.
- **Total Records:** Shows the number of analyzed records.
- **Maximum Salary:** Highlights the highest recorded salary.
- **High Salary Share:** Displays the percentage of high-salary records.
- **Experience Level Filter:** Enables users to explore salary metrics by experience level.
- **Salary Comparison Charts:** Visualizes salaries across different job roles and experience levels.

## Dataset
The original dataset contains 5,000 records, while the cleaned dataset used in the dashboard contains 2,064 records.

The dataset includes job titles, experience levels, company locations, employment types, industries, and salary information.

## Key Insights
- Average Salary: **$99,182.55**
- Maximum Salary: **$361,230**
- Total Analyzed Records: **2,064**
- High Salary Share: **16.28%**

These figures represent the overall dashboard results before applying experience-level filters.
